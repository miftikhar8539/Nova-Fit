# 🏋️‍♂️ NovaFit Activewear — E-Commerce Web Application

NovaFit is a modern, fast, and responsive e-commerce front-end application built for activewear and fitness gear. It features interactive product preview lookbooks, custom category filtering, page pagination, independent thumbnail image carousels, and dynamic cart threshold calculations.

---

## 🌟 Key Features

- **Centralized Product Engine:** All products, prices, badges, and metadata are driven by a central JavaScript database structure across all pages.
- **Interactive Lookbook (Landing Page):** Hotspot pins on banner images dynamically inspect and update product details in real-time.
- **Smart Shop Filtering & Pagination:** Filter products by category, price ranges, size, and swatches with instant smooth transitions and paginated views.
- **Independent Thumbnail Carousel:** Browse thumbnail images independently without disrupting the main product gallery layout.
- **Dynamic Offer Badges:** Automatic display of **30% OFF** and **Free Shipping** badges based on quantity × price threshold rules (>= Rs. 3,000).
- **Responsive Navigation:** Smart scrolling header, expandable quick-search bar, and smooth mobile sidebar drawer.

---

## 🛠️ Built With

- **HTML5:** Semantic structural layout.
- **CSS3:** Custom responsive layout, Flexbox, Grid, transitions, and media queries (No UI Frameworks used).
- **Vanilla JavaScript (ES6+):** Pure DOM manipulation, state management, and event-driven updates.
